# Fonts

`PlotSans-Regular.ttf` is a modified version of Fira Sans Regular, used to embed text in the PDF export.

- Source: Fira Sans Regular (OpenType-CFF), copyright 2012-2015 The Mozilla Foundation and Telefonica S.A.
- Modifications: subset to Latin and the symbols µ, λ, ×, −, –, —, thin space; outlines converted to TrueType; font renamed to PlotSans.
